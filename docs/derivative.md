# 二次开发说明

维护者：EmoXW。

本项目基于 [tangqingfeng7/Oopzbot](https://github.com/tangqingfeng7/Oopzbot)，
上游基线为 `856ee9d`。保留上游提交历史和贡献者记录；原项目 README 标注 MIT，
本版本保留该许可证声明及源码中已有的归属信息。

## 当前改动

- 移除网页屏幕共享：会话与令牌模块、发起和观看页面、频道命令、后台管理、角色权限、配置、部署与镜像资源检查。
- 移除 QQ 音乐：平台适配器、中文和斜杠命令中的平台入口、网页配置、平台标签和相关文档。
- 保留网易云与 B 站音乐、语音频道播放、播放器、后台、频道管理、定时提醒、插件和 OneBot v11。
- Web API 不再解析 QQ 音乐平台，请使用 `netease` 或 `bilibili`。

配置方式和部署步骤见 [快速开始](quickstart.md) 与 [配置说明](configuration.md)。
Docker 必须从本仓库源码构建，使用上游镜像不会包含本版本的修改。
