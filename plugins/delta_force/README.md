# 三角洲插件

源码位于项目 `plugins/delta_force/`，随机器人镜像预装。针对本机 `http://127.0.0.1:8765/openapi.json` 提供的 WeGame API 编写，不依赖旧三角洲插件或第三方积分 API。

## 安装与配置

1. 更新机器人镜像后，在后台“插件”页面查看已加载的 `delta_force`。如果此前手动卸载过，点击加载；无需上传 ZIP。
2. 编辑 `delta_force` 配置，填写 API 后台创建的 `api_key` 和 `api_secret`。后台管理员密码不能代替 API 密钥。
3. 配置 `api_base_url`：机器人直接在本机运行时填 `http://127.0.0.1:8765`；Docker Desktop 容器访问本机 API 时填默认的 `http://host.docker.internal:8765`。API 必须监听容器能访问的地址；若 API 也在 Docker，优先使用同一 Docker 网络的服务名。Linux 服务器请使用实际可达的地址或配置 host-gateway。
4. 机器人后台的“播放器 URL”填写用户实际可访问的站点，例如 `https://music.emoxw.cn`。登录网页自动使用该设置，不能填写 `/admin` 页面地址。该域名的 `/_plugins/delta_force/` 路径需反代到机器人后台的同一个 Web 端口。
5. 保存插件配置后，发送下面的指令。

镜像包含插件免艾特路由，支持直接发送“三角洲 xx”。插件代码随镜像更新，API 密钥和登录绑定保存在原有持久化目录。

## 指令

以下指令均可直接发送，也可在前面加 `@机器人`；不注册斜杠指令。

| 指令 | 说明 |
| --- | --- |
| `三角洲 帮助` | 显示指令说明 |
| `三角洲 登录` | 默认 QQ 登录，私信发送扫码网页 |
| `三角洲 登录 qq` | 指定 QQ 登录 |
| `三角洲 登录 wx` | 微信登录 |
| `三角洲 状态` | 查看绑定会话状态 |
| `三角洲 每日密码` | 无需登录，查看今日地图密码 |
| `三角洲 每日密码 大坝` | 查询指定地图，也可用“密码” |
| `三角洲 信息` | 当前登录渠道的角色信息 |
| `三角洲 统计 12` | 查询赛季 ID 12 的烽火地带统计，12 只是示例，请填写实际赛季 ID |
| `三角洲 统计 12 全面` | 指定全面战场 |
| `三角洲 战绩` | 最近 5 场烽火地带战绩 |
| `三角洲 战绩 全面 10` | 最近 10 场全面战场战绩，最多 20 场 |
| `三角洲 解绑` | 删除当前 API 会话和本地账号绑定 |

也接受“登陆”作为“登录”的同义词。只有前缀独立成词时才会匹配，例如“三角洲玩家”不会触发。首次查询需先登录。本地 WeGame API 没有每日密码接口，插件独立读取 Tmini 的公开每日密码接口，不向该来源发送用户 ID、游戏 Cookie 或 API Key/Secret。`daily_password_url` 可配置兼容数据源。成功结果缓存 5 分钟，失败后至少等待 60 秒再请求；同时校验更新日期和日期标识，不返回昨日密码。不提供当前 API 未支持的日报、周报指令。

## 登录网页与数据

- 登录网页与机器人后台共用 Web 服务，无需新增端口。链接使用随机临时令牌，不包含 API 密钥、上游会话 ID 或用户 ID；请勿转发。
- 默认等待上限 300 秒，受 API 二维码实际有效期限制。每次轮询至少间隔 2 秒，并尊重 API 返回的等待间隔；页面不会直接请求上游 API。
- 关闭网页不影响机器人端检测。成功、失效、验证要求或异常均在网页显示结果，并通过私信通知。私信发送失败会重试，最终失败会显示在网页中；登录链接发不出去时不会泄漏到群聊。
- 登录成功只表示登录 WeGame 成功，不保证当前 QQ/微信渠道及游戏大区有角色。没有角色时显示对应说明。
- 账号绑定保存在数据挂载目录 `data/delta_force/bindings.sqlite3`，仅存用户与 API 会话的关联；游戏 Cookie 仍由 API 服务管理。API 服务自身也需持久化它的数据。
- 预装代码位于 `/app/plugins/delta_force/`；镜像升级不会覆盖绑定数据和 `config/plugins/delta_force/config.json`。如存在同名 `data/plugins/delta_force/` 上传副本，它会覆盖预装版本，应迁走该副本后再使用预装代码。
- 已登录的绑定在热重载和重启后保留；尚未完成的扫码在插件重载/卸载后取消并私信提醒。临时网页是内存状态，重启后失效。
- 预装代码随镜像升级。如需自行修改，也可上传同名 ZIP 覆盖或修改源代码后点击“重载代码”。卸载时会取消轮询、移除网页路由、关闭 HTTP 和数据库连接。

## 验证范围

项目 `tests/test_delta_force.py` 使用带真实 HMAC 校验的本地模拟 HTTP API 验证 QQ 默认渠道、微信失败、成功绑定、二维码代理、网页状态、会话隔离、绑定持久化、私信失败与卸载清理。机器人源码中的 `tests/test_plain_plugin_commands.py` 验证两种命令入口、前缀边界与管理员权限。

真实 QQ/微信扫码与 Oopz 私信收发需要配置 API Key/Secret 和机器人账号后人工联调，模拟测试不代表真实账号已登录。

角色信息使用中文字段和千位分隔数字，隐藏大区编号、头像 URL 及未知字段。角色名保留 API 返回值，不会把数字名称自行改成其他昵称。
